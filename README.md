# My Portfolio project
Welcome to My Portfolio project.
This project have been design just for fun. But the design is base on the most recent technologies and best practices.

## Backend
The backend of this project is made using Node.js and NestJS framework with Mongoose connector for MongoDB database.
The database is hosted on the cloud in Atlas DBaaS runing on an AWS instance.
The backend main controller host in the root of the server the static files build from the frontend. This is how the backend and the frontend has been unified to facilitate the project deploiement.
[Go to backend folder](api/README.md)


## Frontend
The frontend of this project is made using React and Create React App tool.
The component has been develop using function component. Many hooks have been used to build a clean, efficient and reusable source code.
Global states has been manage using Context.
[Go to frontend folder](app/README.md)
